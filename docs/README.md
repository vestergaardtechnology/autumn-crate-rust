# autumn-sdk guides

| Guide | What it covers |
|---|---|
| [Getting started](getting-started.md) | Install, authenticate, the core check / track / attach loop |
| [Configuration](configuration.md) | Builder options, environment variables, per-call options, retries, logging |
| [Models](models.md) | Request builders, nullable fields, enums, unions, approval-rule filters |
| [Errors](errors.md) | The `Error` type, API error codes, validation errors |
| [Fail-open and edge routing](fail-open-and-edge.md) | What happens when Autumn is slow or down, and how the edge works |
| [Migrating from autumn-js](migrating-from-js.md) | Side-by-side mapping of every JS concept to the Rust API |

The API reference is generated by rustdoc (`cargo doc --open`). Every method shows a compiled example, and every request and response field carries Autumn's own documentation.

The [`examples/`](../examples) directory has runnable programs:

| Example | |
|---|---|
| [`quickstart`](../examples/quickstart.rs) | Create a customer, check access, track usage |
| [`billing`](../examples/billing.rs) | Preview, attach with checkout, cancel, customer portal |
| [`usage`](../examples/usage.rs) | Check, track, atomic check + track, locks, LLM tokens, batch tracking |
| [`errors`](../examples/errors.rs) | Error handling, retries, per-call options, clearing fields |

Run one with `AUTUMN_SECRET_KEY=am_sk_test_... cargo run --example usage`.
